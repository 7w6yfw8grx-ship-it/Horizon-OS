\# HorizonOS



Built for people, not money.



HorizonOS is a hobby operating system project aimed at creating a modern, user-focused operating system built from the ground up.



\## Current Status



\- Successfully builds using EDK II

\- Generates Horizon.efi

\- Boots successfully in VirtualBox using UEFI

\- Displays the Horizon OS startup screen

\- Development is currently in the prototype stage

\- Version: v0.1.0-alpha



\## Goals



\- Create a custom operating system

\- Develop a graphical user interface

\- Support VirtualBox testing

\- Support testing on real hardware

\- Create a modern blue-themed user experience

\- Build a family-friendly operating system

\- Provide user-controlled updates and recovery tools



\## Technical Information



\- Architecture: x86-64

\- Boot Method: UEFI

\- Primary Language: C

\- Secondary Language: Assembly

\- Development Environment: Visual Studio Code

\- Build System: EDK II

\- Testing Platform: VirtualBox

\- Version Control: GitHub



\## Planned Features



\- Graphical Desktop Environment

\- Lock Screen

\- Login System

\- User Accounts

\- File Explorer

\- Settings Application

\- Recovery Environment

\- Family Manager Accounts

\- Safe Mode

\- Automatic Recovery Tools



\## Hardware Testing



Planned real hardware testing will be carried out using an AMD Phenom II based system.
