\# HorizonOS Specification



\## Identity



\*\*Name:\*\* HorizonOS



\*\*Slogan:\*\*  

Built for people, not money.



\*\*Primary Colour:\*\*  

Blue



\## Technical



\*\*Architecture:\*\*  

x86-64



\*\*Boot Method:\*\*  

UEFI



\*\*Programming Languages:\*\*  



\- C

\- Assembly



\*\*Development Environment:\*\*  



\- Visual Studio Code

\- EDK II

\- Visual Studio 2022 Build Tools



\*\*Testing Platform:\*\*  



\- VirtualBox



\*\*Version Control:\*\*  



\- GitHub



\## Users



\*\*Account Types:\*\*



\- Family Manager

\- Standard User

\- Restricted User



Multiple Family Managers are supported.



\## Updates



\- User-controlled updates

\- Rollback created before each update

\- Rollback retained for 4 days

\- Automatic recovery available after boot failures

\- Update verification before installation



\## Features



\- Lock Screen

\- Login Screen

\- Safe Mode

\- Recovery Tools

\- Friendly Error Messages

\- Advanced Mode

\- Standard Mode

\- Blue-themed Interface

\- Family Management Tools



\## Security



\- URL Blocking

\- Adult Content Filtering

\- Application Restrictions

\- Password-Protected Restrictions

\- Recovery Protection

\- Account-Based Permissions



\## Philosophy



\- Fast and modern

\- Designed to work offline

\- Internet connection recommended, not required

\- User-first design

\- Built for learning and experimentation

\- Built for people, not money
